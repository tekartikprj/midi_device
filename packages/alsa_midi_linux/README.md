# tekartik_alsa_midi_linux

Raw MIDI on Linux from Dart, through ALSA (`libasound.so.2`) and `dart:ffi`:
list the MIDI devices of the sound cards, send bytes, and receive complete
MIDI messages (running status, real-time bytes and sysex handled). Linux
only: the Dart VM and Flutter desktop.

For one API on several platforms, use `tekartik_midi_device` with
`tekartik_midi_device_alsa_linux` (built on this package), in the same
repository.

## Getting started

Not on pub.dev, add it as a git dependency:

```yaml
dependencies:
  tekartik_alsa_midi_linux:
    git:
      url: https://github.com/tekartikprj/midi_device
      path: packages/alsa_midi_linux
```

The machine needs `libasound.so.2` (package `libasound2`, `libasound2t64`
on Ubuntu 24.04 and later; desktop distributions have it) and access to
`/dev/snd` (the desktop user has it, or add the user to the `audio` group).

```dart
import 'dart:typed_data';

import 'package:tekartik_alsa_midi_linux/midi.dart';

Future<void> main() async {
  final devices = AlsaMidiDevice.getDevices();
  if (devices.isEmpty) {
    print('no MIDI device');
    return;
  }
  final device = devices.first;
  if (!await device.connect()) {
    print('cannot open ${device.name} (busy in another program?)');
    return;
  }
  final subscription = device.receivedMessages
      .where((message) => message.device == device)
      .listen((message) => print(message.data));
  device.send(Uint8List.fromList([0x90, 60, 100])); // note on, middle C
  await Future<void>.delayed(const Duration(seconds: 1));
  device.send(Uint8List.fromList([0x80, 60, 0])); // note off
  await subscription.cancel();
  device.disconnect();
}
```

## API

- `AlsaMidiDevice.getDevices()`: the raw MIDI devices (`hw:<card>,<device>`,
  `AlsaMidiDevice.hardwareId`), the connected ones included. Call it again
  after a plug or an unplug.
- `connect()`: opens the device and starts a receive isolate; false when
  it cannot be opened.
- `receivedMessages`: the complete messages (`MidiMessage`: `data`,
  `timestamp` in ms since epoch at reception, `device`).
- `send(bytes)`: writes whole messages, status byte first.
- `disconnect()`: closes it; `AlsaMidiDevice.onDeviceDisconnected` emits it
  (also after a read error such as an unplug).

The examples (`dart run example/midi_receive_example.dart`, `..._send_...`,
`..._receive_sysex_...`) use the first device found.

## Common mistakes

- Ignoring the result of `connect()`: a device opened by another program
  (a DAW, another instance) cannot be opened.
- No `disconnect()` at the end (ctrl-C included): the device stays busy.
- Several devices connected from one `getDevices()` call share one
  `receivedMessages` stream: filter on `message.device`.
- Clock (0xF8) and active sensing (0xFE) arrive all the time from many
  devices: filter them before logging.
- A message longer than 4 KB (a big sysex dump) is cut: the output is
  non-blocking and `send` does not retry.
- `MidiMessage` here is not the `MidiMessage` of `tekartik_midi_device`:
  prefix one of the imports.

## Bindings

`lib/alsa_generated_bindings.dart` is generated by `dart run ffigen` (the
`ffigen:` section of `pubspec.yaml`), which needs the ALSA headers
(`libasound2-dev`) and libclang. Do not edit it by hand.
